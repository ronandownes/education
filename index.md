## Hope · Expectation · Trust 

This is the organising idea behind the site. **Hope** that progress is possible; **expectation** that students engage, behave and move forward; **trust** that the classroom is fair, safe and purposeful.

## How this site is organised

Use the menus across the top. **Practice** holds interview answers by professional domain. **Subjects** holds subject-specific material. **Schools** holds school-specific research. **Interview** holds the short notes that can be printed or used for rehearsal.

## Editing

The words are being moved out of code and into ordinary document files. The **Edit content** button opens the browser-based content editor. Changes made there are saved back to GitHub rather than only to one browser.

## Privacy while this is being built

No student names or confidential student information belong on the published site. The site is also marked **noindex** while it is a working draft, although a noindex instruction does not make a public web address private.
