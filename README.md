## Editing

The working content now lives in Markdown files and the repository includes a `.pages.yml` configuration for browser-based rich-text editing with Pages CMS.

## Publishing

GitHub Pages publishes from `main` / root. The site is marked `noindex` while it is a working draft. Do not add student names or confidential student information to the published repository.
